# La Galerie EXIT - Site Officiel

## Description du Projet
Développement d'une plateforme web haut de gamme pour **La Galerie EXIT** (Aix-les-Bains). Le site adopte un design de type "Editorial" (style magazine de luxe) axé sur l'art contemporain.

## Fonctionnalités Clés (Développement du [Встав дату])
- **Background Génératif :** Système de particules dorées interactives utilisant l'API HTML5 Canvas pour une ambiance immersive.
- **Hero Section Éditoriale :** Mise en page asymétrique avec typographie imposante et visuels dynamiques.
- **Navigation Avancée (Mega Menu) :** Menu déroulant structuré en colonnes pour une exploration fluide des catégories.
- **Carrousels Interactifs :** - Système "Drag-to-Scroll" (glisser-déposer).
  - Navigation par boutons directionnels intelligents (visibilité adaptative).
  - Effets de Glassmorphisme (flou d'arrière-plan).
- **Identité Visuelle :** Logo interactif avec animation CSS3 sur l'icône "Power-e".

## Stack Technique
- **Backend :** PHP (Structure modulaire Header/Footer).
- **Frontend :** HTML5, CSS3 (Variables natives, Flexbox/Grid), JavaScript (Vanilla JS).
- **Versionnage :** Git / GitHub.
